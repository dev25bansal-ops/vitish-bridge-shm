# Crack-Seg Converter — real crack image sets → YOLO-seg training data

Builds a single-class (`crack`) YOLO-seg dataset from **real crack imagery** so
the twin's crack detector is trained on real photos, not hand-drawn blobs. Two
conversion scripts, one honest caveat per source — the *data* license governs
what you may republish, the *code* license only governs the code itself.

## Scripts

| Script | Source dataset | Turns it into |
|---|---|---|
| `prep_crackseg9k.py` | **CrackSeg9k** (CC0) — 9,159 real bridge-wall crack photos + soft masks | YOLO-seg, keeping the dataset's own train/val split (no leakage) |
| `prep_sdnet.py` | Priority chain: **Ultralytics crack-seg** zip → **SDNET2018** (local, registration-gated) → synthetic | YOLO-seg; SDNET classification crops get *approximate* segmentation from edges/contours (documented as approximate); failure falls back to synthetic so training code stays exercisable |

Mask binarization (CrackSeg9k): soft anti-aliased masks are thresholded at 127
(half-intensity) to recover the core crack footprint, outer contours simplified
with `approxPolyDP`, noise contours (< 15 px) dropped, polygon points capped at
the ultralytics label limit.

## Run

```bash
python prep_crackseg9k.py                                   # CrackSeg9k parquet → data/cv/yolo9k
python prep_sdnet.py --out data/cv/yolo --dataset ultralytics   # default source
python prep_sdnet.py --out data/cv/yolo --dataset sdnet --sdnet-path <dir>
```

## Data license matrix (CRITICAL — code license ≠ data license)

| Source | License | Publish / redistribute? |
|---|---|---|
| **CrackSeg9k** | CC0 (public domain dedication) | ✅ Yes — republish freely with attribution |
| **Ultralytics crack-seg** | MIT (code); dataset redistribution terms should be verified before mirroring the zip | ⚠️ Verify before mass redistribution; fine for local training |
| **SDNET2018** | IEEE DataPort **registration-gated** | ❌ **Ingest-only — NEVER redistribute.** Approximate labels generated locally only |
| synthetic fallback | generated by this repo's code | ✅ Yes |

Per VITISH's §7.6 item-19 publishing rule, **only the CC0 CrackSeg9k path and
the synthetic fallback are publishable artifacts**; SDNET2018-derived data stays
out of any public package or commit (see `docs/REUSABLE-PIPELINES.md`).

## Provenance

- **CrackSeg9k:** downloaded 2026-08-14; real bridge-wall crack dataset
  (parquet: `data/cv/crackseg9k/{train,test}.parquet`). Embedded base64 PNGs.
- **Ultralytics crack-seg:** ~91.6 MB,
  `github.com/ultralytics/assets/.../crack-seg.zip`, YOLO-seg format already.
- **SDNET2018:** registration at IEEE DataPort; classification-only, 56k+ crops,
  per-pixel labels require registration consent.
